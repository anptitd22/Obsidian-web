Giúp cấu hình và chạy các ứng dụng đa container như network, environment, config, ...; đảm bảo tính nhất quán của dự án.

**Dockerfile so với Composefile**: Dockerfile cung cấp các hướng dẫn để xây dựng image container, trong khi Compose file định nghĩa các container đang chạy. Thông thường, Compose file sẽ tham chiếu đến Dockerfile để xây dựng image dùng cho một dịch vụ cụ thể.
